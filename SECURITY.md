# Security Policy

## Reporting Security Issues

The Carvel maintainers take security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them through our [private vulnerability reporting](https://github.com/carvel-dev/carvel-dev/security/advisories/new) form.

For more details, see the [Carvel security policy](https://github.com/carvel-dev/carvel-dev/blob/main/SECURITY.md).
